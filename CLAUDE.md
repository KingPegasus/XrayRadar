# CLAUDE.md

## Changelog

- Never add an `## [Unreleased]` section to `CHANGELOG.md`.
- Every entry goes under a versioned, dated heading: `## [X.Y.Z] - YYYY-MM-DD` (Keep a Changelog format, as in the existing entries).
- If the change has no version yet, ask which version to use rather than writing `Unreleased`.
